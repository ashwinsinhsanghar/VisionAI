# VisionAI

आपके SHG Smart Vision Glasses से अपनी Gemini key, अपना करेंसी मॉडल और
Google के खुले MediaPipe मॉडल जोड़कर बना एक निजी-इस्तेमाल ऐप। कंपनी की
ऐप का कोई मॉडल, key या कोड इसमें कॉपी नहीं किया गया है — सिर्फ़ ग्लासेस से
जुड़ने का तरीका (Wi-Fi Direct + port 8080 + capture.cgi) वही रखा गया है,
क्योंकि वह ग्लासेस के फ़र्मवेयर का हिस्सा है, ऐप का नहीं।

## पहली बार सेटअप

2. उसके बाद सामान्य **build.yml** workflow चलाइए (push पर अपने-आप चलेगा)।
   बनी APK आपके Telegram ग्रुप में आ जाएगी।
3. ऐप खोलकर **सेटिंग्स → Gemini API Key** में अपनी मुफ़्त key डालिए
   (https://aistudio.google.com से बनती है)।
4. **ग्लासेस से जोड़ें** दबाइए, ज़रूरी permissions दीजिए, फिर ग्लासेस की
   अपनी ऐप की तरह उसी Wi-Fi नेटवर्क से ग्लासेस को जोड़िए (QR या manual)।

## ग्लासेस के टैप/स्वाइप

| इशारा | काम |
|---|---|
| एक टैप | आसपास क्या है (Gemini) |
| डबल टैप | पढ़ना (Gemini) |
| लंबा टैप | नोट पहचानें (आपका मॉडल) |
| Walking प्रेस | चलने में मदद (MediaPipe) |

यह मैपिंग `MainActivity.onGlassesTap()` में है, आसानी से बदली जा सकती है।

## अधूरे / अनिश्चित हिस्से (ईमानदारी से बताना ज़रूरी)

- **ग्लासेस का प्रोटोकॉल** कंपनी की ऐप के कोड से निकाला गया है, असली
  ग्लासेस पर अभी परखा नहीं गया। अगर कोई संदेश न मिले या कैमरा जवाब न दे,
  तो Logcat से लॉग भेजिए, ठीक किया जा सकता है।
- **currency_model.tflite**: असली ऐप के कोड से पुष्टि करके अब Google ML Kit
  की Custom Image Labeling API से चलाया जाता है, raw TFLite Interpreter से
  नहीं, ताकि मॉडल की अपनी embedded preprocessing/labels सही इस्तेमाल हों।
  **सीमा:** असली ऐप इसे चलाने से पहले एक अलग YOLO मॉडल से नोट detect+crop
  करता है, जो proprietary होने से इस प्रोजेक्ट में नहीं है। इसलिए नोट को
  फ़्रेम भरते हुए पकड़ना बेहतर नतीजा देगा।
- **MediaPipe मॉडल** पहली बार इंटरनेट से अपने-आप डाउनलोड होता है
  (Google की आधिकारिक लिंक से)। ऑफ़लाइन चाहिए तो इसे मैन्युअल डाउनलोड
  करके `assets/efficientdet_lite0.tflite` में रखें और कोड में
  `BUNDLED = true` कर दें।
- **Gemini कॉल** अभी साधारण request/response है (streaming "Live" नहीं)।
  हर टैप पर 1-3 सेकंड लग सकते हैं। असली Live API (websocket, लगातार आवाज़)
  जोड़ना अगला कदम है, चाहें तो वह भी बना दूँगा।
- चलते समय सिर्फ़ इस ऐप के वर्णन पर निर्भर न रहें — यह सहायक है, पूरी तरह
  भरोसेमंद नेविगेशन उपकरण नहीं।
